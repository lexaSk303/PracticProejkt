## Практическая работа №3

### 1. Выбранные работы проекта - WBS AutoStock
1. Сбор и анализ бизнес-требований.
2. Проектирование структуры базы данных.
3. Создание макетов пользовательского интерфейса (UI/UX).
4. Разработка API авторизации и ролей (Admin, Кладовщик).
5. Разработка API операций склада (приход, расход, перемещение).
6. Верстка и логика frontend-интерфейса.
7. Интеграция frontend и backend.
8. Написание тестовых сценариев (Test Cases).
9. Функциональное тестирование системы.
10. Подготовка пользовательской документации и развёртывание.

### 2. Матрица ответственности RACI

| Задача | Руководитель (PM) | Аналитик / Дизайнер (BA) | Разработчик (DEV) | Тестировщик (QA) |
| --- | --- | --- | --- | --- |
| 1. Сбор и анализ требований | A | R | C | I |
| 2. Проектирование структуры БД | I | C | A/R | I |
| 3. Создание макетов интерфейса  | I | A/R | C | I |
| 4. Разработка API авторизации и ролей | I | C | A/R | I |
| 5. Разработка API операций склада | I | C | A/R | C |
| 6. Верстка и логика frontend-интерфейса | I | C | A/R | I |
| 7. Интеграция frontend и backend | A | I | R | C |
| 8. Написание тестовых сценариев  | I | C | I | A/R |
| 9. Функциональное тестирование системы | I | I | C | A/R |
| 10. Подготовка документации и развёртывание | A | R | C | I |

### 3. Проверка матрицы на соответствие правилам:
-  У каждой задачи есть минимум один R (Исполнитель)
-  У каждой задачи ровно один A (Ответственный)
-  Нет задач без ответственного (пустых строк по вертикали A/R)
-  Все участники задействованы и имеют понятные зоны ответственности
-  Количество C (Консультируемых) ограничено, чтобы не замедлять процесс (в основном это аналитик при разработке и разработчик при тестировании)
